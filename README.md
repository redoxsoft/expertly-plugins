# Expertly plugins

Expertly: a team of named experts inside your AI assistant.

Version 0.1.0. Generated from the Expertly repo by `npm run package:build`; don't edit by hand.

## Install

- **Claude Code:** `claude plugin marketplace add https://github.com/redoxsoft/expertly-plugins.git`, then `claude plugin install expertly@expertly`
- **Codex:** `codex plugin marketplace add https://github.com/redoxsoft/expertly-plugins.git`, then `codex plugin add expertly@expertly`
- **Cursor:** `cursor-agent plugin marketplace add https://github.com/redoxsoft/expertly-plugins.git`, then install Expertly from Cursor's plugin list
- **claude.ai, Claude Desktop:** Settings → Connectors → Add custom connector → `https://expertly-mcp.redoxsoft.com/mcp`

Then sign in to Expertly when your assistant asks, and say "/expertly".
